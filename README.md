# CataclysmClass

Paper 1.20.1 plugin integrating with AuraSkills 2.2.0.

## Features
- /class opens a 9x4 class GUI.
- Fighter: Fighting, Foraging, Excavation x1.5
- Ranger: Archery, Fishing, Agility x1.5
- Tanker: Defense, Mining x1.5
- Mage: Farming, Enchanting, Alchemy x1.5
- Class can only be selected once.
- /classadmin reset <player>
- /classadmin info <player>
- /classadmin reload
- No MMOCore.

AuraSkills XP is modified through XpGainEvent after AuraSkills's normal multipliers have been applied.
